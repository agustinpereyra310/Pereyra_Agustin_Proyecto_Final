SISTEMA DE SOCIOS - BOCA
========================

Sistema web de registro, inicio de sesion y administracion de usuarios
hecho con PHP, MySQL (PDO), HTML y CSS.


REQUISITOS
----------
- XAMPP (o Laragon) con Apache y MySQL
- Un navegador


INSTALACION
-----------
1. Copiar la carpeta del proyecto (Boca_socios) dentro de:
      C:\xampp\htdocs\

2. Abrir el panel de XAMPP y encender Apache y MySQL (boton "Start").

3. Abrir phpMyAdmin en el navegador:
      http://localhost/phpmyadmin

4. Ir a la pestania "Importar", elegir el archivo boca_socios.sql
   y presionar "Importar". Esto crea la base "boca_socios" y las tablas
   "usuarios", "partidos" y "entradas_socios".

5. Abrir el sistema en el navegador:
      http://localhost/Boca_socios/

   (El nombre debe coincidir con el de la carpeta que copiaste a htdocs.)


CONEXION A LA BASE DE DATOS
---------------------------
Los datos estan en conexion.php. Vienen con los valores por defecto
de XAMPP:
   host: localhost
   base: boca_socios
   usuario: root
   contrasenia: (vacia)
Si tu MySQL usa otros datos, modificalos en ese archivo.


COMO CREAR EL PRIMER ADMINISTRADOR
----------------------------------
1. Entrar a http://localhost/Boca_socios/registro.php y registrar
   una cuenta normal.
2. En phpMyAdmin, abrir la base "boca_socios", pestania "SQL", y ejecutar
   (cambiando el correo por el que usaste):

      UPDATE usuarios SET rol = 'admin' WHERE email = 'tu_correo@ejemplo.com';

3. Cerrar sesion y volver a iniciar. Ahora se accede al panel
   administrativo.

panel.php               Panel personal del usuario
cerrar_sesion.php       Cierre de sesion

archivar_usuario.php    Archivado de cuentas (no se borra nada)

reactivar_usuario.php   Reactivacion de cuentas archivadas
styles.css              Estilos de la interfaz
boca_socios.sql         Script para crear la base de datos y la tabla
